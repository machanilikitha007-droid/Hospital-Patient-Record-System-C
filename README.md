# Hospital Patient Record System

## Project Description

A simple C program to store and manage basic patient records in a hospital.

## Features

- Add Patient
- View Patients
- Search Patient
- Exit

## Technologies Used

- C
- Structures
- Arrays
- Loops
- Conditional Statements

## How to Run

Compile and run the `patient_record.c` file using a C compiler.
